# 🎃 The Worst Game Ever 👻

**[▶ Play it here](https://isabellagreco1997.github.io/worst-game-ever/)**

My entry to the **🎃 Worst Game Ever Challenge 💀** in the AI Game Makers Club, Halloween edition.

You are a ghost (probably). Get the candy. The candy does not want to be got.

![The Worst Game Ever](docs/gameplay.png)

## Features nobody asked for

- the controls are wrong, then they get patched, then gravity gets haunted
- a loading bar that goes backwards
- cookie consent with two Accept buttons
- an ad that comes back from the dead
- dying gives you points
- a final boss with 1 HP
- a Play again button that runs away

Arrow keys or WASD. M to mute. On-screen buttons on phones.

## Your turn

Make the most broken, ugly, pointless game you can with AI, and post it in the club. Worst game wins.
